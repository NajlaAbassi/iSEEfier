# Changelog

## iSEEfier 1.2.0

- Adding in a new function [`iSEEmarker()`](../reference/iSEEmarker.md),
  more focused on finding marker genes
- A new [`iSEEinit()`](../reference/iSEEinit.md) version without the
  `DynamicMarkerTable` panel
- Expanding the input of [`iSEEinit()`](../reference/iSEEinit.md) to
  accept features as `data.frame` in addition to `vector`
- Adding visualization plots to
  [`iSEEnrich()`](../reference/iSEEnrich.md)
